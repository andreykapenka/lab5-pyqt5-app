# ЛАБОРАТОРНАЯ РАБОТА №5
Разработка многомодульного приложения для получения и хранения данных

## Файлы:
main.py - запуск программы.
main_window.py - главное окно.
table_window.py - окно с таблицей.
data_reader.py - получение тестовых данных.
data.csv - сохранение результатов.
main_window.ui - интерфейс главного окна Qt Designer.
table_window.ui - интерфейс окна таблицы.
requirements.txt - библиотека PyQt5.

## Запуск:
1. Открыть папку проекта в VS Code.
2. Открыть терминал.
3. Выполнить: pip install -r requirements.txt
4. Выполнить: python main.py

## Проверка:
1. В главном окне нажать "Открыть таблицу данных".
2. В окне таблицы нажать "Считать данные".
3. Появится строка: 23, 85, 800.
4. Нажать "Считать данные" несколько раз для добавления новых строк.
5. Нажать "Сохранить".
6. Открыть data.csv и проверить сохранённые строки.

## Для подключения Arduino:
data_reader.py уже содержит место, где тестовая строка "23,85,800"
может быть заменена чтением строки из COM-порта Arduino.
